# Proposed contribution model

Contributions will be accepted through public issues and pull requests after the repository is published.

A new fixture should include:

- the smallest synthetic input that reproduces one metadata behaviour;
- a short explanation of the Maven or JAR rule being exercised;
- deterministic build instructions;
- machine-readable expected observations;
- licensing and redistribution information;
- tests that do not require private services or credentials.

Tool-specific differences should be described neutrally. An unsupported assertion is not automatically a tool defect, and findings should be discussed with upstream maintainers before being characterised as bugs.

No proprietary customer code, credentials, personal data or restricted artefacts may be contributed.
